**Tech Stack:** TypeScript, HTML, CSS, JavaScript  

---

## 🌍 Project Overview
Wi-Fi in Tanzania is a web platform built with **TypeScript** to help users **discover Wi-Fi hotspots** and **relaxation areas** across different regions of Tanzania.  
The goal is to provide a simple and intuitive way for locals and travelers to locate connectivity spots and rest areas effortlessly.

---

## ✨ Key Features
- 📶 **Wi-Fi Hotspots Map** – Quickly find available Wi-Fi in various cities  
- 🏖️ **Relaxation Locations** – Discover peaceful places to unwind  
- 🧭 **Interactive UI** – Modern, responsive, and TypeScript-driven interface  
- 📱 **Mobile-Friendly** – Works seamlessly on phones, tablets, and desktops  

---

## 🧰 Technologies Used
- **Frontend:** TypeScript, HTML, CSS  
- **Styling:** Responsive design and simple animations
